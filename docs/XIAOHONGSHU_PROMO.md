## 正文（可直接复制）

做鸿蒙 NEXT 开发这段时间，最难受的是：
想找一个原生、顺手的 AI 对话 App，一直没找到。

于是干脆自己写了一个：**鸿语**。

它不是网页套壳，是 ArkTS + ArkUI 原生开发。

✔ 多会话：新建、置顶、重命名、删除
✔ 多图理解：一次最多 9 张，支持系统相机拍照
✔ 语音朗读：系统离线 + DeepSeek 在线（海星/暗潮）
✔ 深色 / 浅色 / 跟随系统，字体大小可调
✔ 支持导入 DeepSeek 聊天记录
✔ 还能和电脑 DSH 局域网同步文字对话

说点真实的：

• 不是 DeepSeek 官方，需要自己填 API Key，API 费用自理
• 贝壳/白浪是 DeepSeek App 的私有音色，公开接口没有，我只能用海星/暗潮
• 目前源码已经 MIT 开源
• 华为应用市场还在走版权、备案和审核，普通用户先别急，上架后我第一时间更新

想先看代码 / 自己编译：

安装说明书也放在主页了。
