鸿语

HarmonyOS NEXT · AI 对话助手

多会话、多图理解、语音朗读、DeepSeek API。第三方开源客户端，需要自备 API Key。

查看安装说明书 下载 PDF 说明书 GitHub 源码

安装方式

普通用户：HarmonyOS NEXT 不能直接点击 HAP 安装。正式安装请等华为应用市场上架，在应用市场搜索“鸿语”。

开发者：克隆源码后用 DevEco Studio 构建，debug HAP 通过 hdc 安装到已注册调试设备。

详细步骤见 安装说明书，内含华为应用市场、AGC 邀请测试、指定设备发布和 hdc 调试安装说明。

界面预览

主要功能

  • 多会话、置顶、重命名、删除
  • 多轮对话，最多 9 张图片理解
  • 系统相机拍照、DeepSeek 聊天记录导入
  • 系统离线朗读 / DeepSeek 在线朗读
  • 浅色、深色、跟随系统，字体大小可调
