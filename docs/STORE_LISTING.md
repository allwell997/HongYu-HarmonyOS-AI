## 简短介绍（约 80 字）

鸿语是一款简洁的 AI 对话客户端，支持多会话、多图理解、语音朗读、深色模式和对话记录导入。需要自备 DeepSeek API Key，数据与 Key 保存在本机。

## 详细描述

鸿语是一款面向 HarmonyOS NEXT 的 AI 对话客户端，交互参考主流 AI 助手：

- 多会话管理：新建、切换、重命名、置顶、删除；支持对话记录导入。
- 多图理解：一次选择多张图片，自动压缩后按视觉模型格式发送。
- 语音朗读：支持 DeepSeek 服务端在线音色（海星/暗潮）和系统离线音色，可随时停止。
- 阅读体验：字体大小可调，支持跟随系统、浅色、深色主题；长对话可用右侧滚动条和上下对话按钮浏览。
- 回答操作：长按回复可复制、选择文本、重新生成、朗读/停止。
- 数据本地优先：对话、图片和设置默认保存在本机；只有在你主动发送消息或试听在线音色时，内容才会发送到你配置的 DeepSeek API。

请注意：

1. 本应用是第三方 DeepSeek API 客户端，不是 DeepSeek 官方应用，与 DeepSeek 官方无隶属关系。
2. 首次使用需要在设置中填写你自己的 DeepSeek API Key；费用由你的 DeepSeek 账号承担。
3. 不使用本应用时，你仍可以直接使用 DeepSeek 官方 App。
4. “贝壳/白浪”是 DeepSeek App 的私有音色，公开 API 不提供；本应用提供官方公开的海星/暗潮在线音色和系统离线音色。
5. 图片、文字和朗读文本会发送到 DeepSeek 进行处理，请勿发送敏感个人信息。
