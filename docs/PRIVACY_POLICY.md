【开发者主体名称】（以下简称“我们”）运营鸿语应用（包名：`com.hongyu.chat`，以下简称“本应用”）。我们重视你的个人信息保护。本政策说明我们如何收集、使用、保存和共享信息。

## 一、我们处理的信息

### 1. 本地保存的信息

为了提供多会话聊天功能，本应用会在你的设备本地保存：

- 你创建的对话标题、消息内容、时间、置顶状态；
- 你选择或拍摄的图片副本（压缩后保存在应用沙箱）；
- 应用设置，包括模型名称、Base URL、API Key、系统提示词、温度、朗读参数、主题、字体大小；
- DSH 同步的主机、端口和配对码（仅在你填写后）。

这些信息默认只保存在本机应用沙箱中，不会自动上传到我们的服务器。本应用没有自有业务服务器。

### 2. 发送给第三方 DeepSeek 的信息

只有当你主动发送消息、测试 API 连接或试听/使用 DeepSeek 在线音色时，本应用才会通过网络向你配置的 DeepSeek API 发送：

- 对话文字、系统提示词、模型参数；
- 你选择或拍摄的图片（Base64 编码）；
- 需要朗读的文本（在线 TTS）；
- 你的 DeepSeek API Key（用于身份验证）。

DeepSeek 对这些信息的处理受其隐私政策和 API 条款约束。请勿发送身份证号、银行卡号、密码、精确住址、医疗记录等敏感个人信息。

### 2.1 发送给 Bing 的搜索查询

联网搜索默认开启。当问题命中“最新、今天、新闻、查询、资料、价格、天气、外部数据”等关键词时，本应用会把**你输入的问题文本**发送到 Bing（`cn.bing.com`）获取网页搜索结果。

- 不发送 API Key、完整对话历史或图片；
- 搜索结果是网页标题、链接和摘要，会作为回答参考交给 DeepSeek；
- 可以在设置中关闭“联网搜索”；
- Bing 对这些查询的处理受 Microsoft 的隐私政策和服务条款约束。

### 3. 系统能力

- 图片选择/拍照使用 HarmonyOS 系统 Picker，本应用只获得你主动选择或确认的照片，不读取整个图库或实时取景。
- 系统离线朗读使用 HarmonyOS Core Speech Kit，在本机合成。
- 在线朗读使用 DeepSeek TTS，需要把待朗读文本发送给 DeepSeek。
- 音频播放使用 HarmonyOS MediaKit。
- 网络请求使用 HarmonyOS NetworkKit。

### 4. DSH 局域网同步（可选）

如果你主动配置并点击同步，本应用会把文字对话发送到你填写的电脑地址（局域网）。该数据不经过我们的服务器。请确保你信任该电脑和局域网环境。

### 5. 我们不收集的信息

本应用不包含广告 SDK、统计 SDK 或用户画像服务，不收集通讯录、短信、通话记录、精确位置、设备广告标识符（OAID）或剪贴板内容。

## 二、权限说明

本应用仅声明以下权限：

- `ohos.permission.INTERNET`：访问你配置的 DeepSeek API、Bing 联网搜索、在线语音合成和你填写的 DSH 同步地址。

图片/相机通过系统 Picker 完成，不申请相册或相机权限；朗读通过系统音频播放完成，不申请麦克风权限。

## 三、信息保存期限与删除

- 对话、图片和设置保存在本机，直到你在应用内删除对话、清除应用数据或卸载应用。
- API Key 保存在本机 Preferences 中；你可以在设置中清空。
- 删除对话会删除该对话关联的图片副本；卸载应用会删除应用沙箱数据。
- 已发送给 DeepSeek 的信息由 DeepSeek 按其政策保存和处理，我们无法直接删除；请通过 DeepSeek 账号渠道处理。

## 四、信息共享

除以下情形外，我们不会向第三方共享你的信息：

1. 你主动使用 DeepSeek API 时，向 DeepSeek 发送必要信息；
2. 你开启联网搜索并命中外部信息问题时，向 Bing 发送问题文本；
3. 你主动使用 DSH 同步时，向你填写的局域网电脑发送文字对话；
4. 法律法规要求或有权机关依法要求。

我们不会出售你的个人信息。

## 五、未成年人保护

本应用不面向不满 14 周岁的儿童单独提供服务。未成年人应在监护人指导下使用，并避免发送敏感个人信息。

## 六、安全措施

我们采用应用沙箱、系统 Picker、HTTPS 请求等措施保护数据。但互联网传输和本地存储不存在绝对安全；请妥善保管 API Key 和设备。

## 七、你的权利

你可以：

- 在应用内查看、删除对话和图片；
- 在设置中修改或清空 API Key、Base URL、DSH 配置；
- 通过卸载应用删除本地数据；
- 通过【联系邮箱】联系我们，行使查询、更正、删除等权利。

## 八、政策更新

我们可能更新本政策。重大变更会通过应用内提示或更新说明告知。继续使用前，如法律要求，我们会重新征得同意。
